# Ideas

Fun ideas we might build, written down so they are not lost. Nothing here is a
commitment, a spec, or a page on the public site. The site (`ui/www`) shows what exists;
this folder holds what could.

## Rules for this folder

- **Not on the site.** Nothing here is linked from `ui/www`, `ui/cv` or the mobile app.
  An idea earns a case study on the site once something measurable has been built.
- **Not a spec.** Like `docs/design/`, this is idea material. When an idea turns into
  work it gets a plan under `docs/plans/` and, if it becomes a service, the scaffold
  (`mise run tbd -- new service <name>`) and a contract under `docs/<name>/`.
- **No private data.** No phone numbers, addresses, references, client names beyond what
  the public site already says, and no content from a client's repositories, current or
  former. The material an idea may draw on is the owner's own work: this repository, the
  owner's own public and private repositories, and the public CV.
- **Honest about the market.** Competitor names and prices are what a quick survey
  found on the day written; check them again before a pitch.
